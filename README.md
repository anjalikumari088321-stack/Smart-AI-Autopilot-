# Smart AI AutoPilot 🚗

### Smart Car Service Assistant

Smart AI AutoPilot is a web-based car service assistant designed to help users access vehicle maintenance information and basic car service support.

## Features
- User Login
- Car Service Information
- Online Service Booking
- Vehicle Breakdown Information
- Maintenance Guidance
- AI-style Chatbot Support
- Customer Feedback
- User Profile

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB

## Project Objective
To provide users with an easy-to-use platform for basic car maintenance guidance and service-related assistance.

## Future Scope
- Android Mobile Application
- Advanced AI Chatbot
- Real-time Service Tracking
- Online Payment Integration
